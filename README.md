# Acelera — Prototipo Comité de Gerencia

Prototipo interactivo (HTML/CSS/JS, sin dependencias) del tablero de Comité de Gerencia de Acelera:
Planeamiento Estratégico, Roadmap Estratégico, OKRs, KPIs, Backlog y Reportes.

## Ver el prototipo

👉 **[Abrir el prototipo](https://valeriagt.github.io/acelera-prototipo/)**

## Presentación final

👉 **[Ver la presentación](https://valeriagt.github.io/acelera-prototipo/presentacion-final.html)** — incluye el reto de negocio, la propuesta, el plan de testeo del prototipo y el prototipo embebido.

## Contenido destacado

- Alertas de completitud en OKRs (iniciativa, responsable, equipo) con modales para resolverlas en el momento.
- Selector de colaboradores y de alineación (KPI / iniciativa) directamente desde cada fila.
- Onboarding guiado (spotlight + tooltips) en Roadmap Estratégico.
